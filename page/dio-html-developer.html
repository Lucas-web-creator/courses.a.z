SOBRE A FORMAÇÃO

Estrutura. Semântica. Web.

O HTML é uma das bases do desenvolvimento Web. Sua utilização permite organizar conteúdos, estruturar documentos e definir o significado dos elementos apresentados ao usuário.

01

O que é?

HTML é a linguagem de marcação utilizada para estruturar conteúdos e elementos presentes em páginas e aplicações Web.

02

O que você aprende?

Estrutura de documentos, elementos, atributos, organização de conteúdo e utilização de HTML semântico.

03
