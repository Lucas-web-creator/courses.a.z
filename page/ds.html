FORMAÇÃO · 001

Desenvolvimento de Sistemas

Uma formação voltada à construção de sistemas, aplicações e soluções digitais, conectando lógica, tecnologia, desenvolvimento e resolução de problemas.

SENAC / DS / 001
01

O que é o curso?

Uma formação construída para compreender o processo de desenvolvimento de sistemas desde a lógica inicial até a construção de aplicações.

O curso de Desenvolvimento de Sistemas trabalha a formação necessária para compreender como sistemas são planejados, estruturados, desenvolvidos e utilizados.

Na minha trajetória, ele representa principalmente a aproximação entre tecnologia e resolução de problemas: transformar uma necessidade em uma solução que possa ser estruturada por meio de código, dados e ferramentas digitais.

02

Como funciona

O aprendizado passa por diferentes etapas que se complementam durante a formação.

ETAPA / 01

Lógica

Desenvolvimento do raciocínio necessário para compreender problemas e estruturar soluções.

ETAPA / 02

Desenvolvimento

Aplicação da lógica na construção de sistemas e soluções utilizando diferentes tecnologias.

ETAPA / 03

Projeto

Organização dos conhecimentos para construir soluções que representem situações práticas.

03

O curso no SENAC

Minha visão sobre como a formação se conecta com a prática.

MINHA VISÃO / 01

Tecnologia aplicada

A formação não fica limitada à ideia de aprender uma linguagem. O conhecimento tecnológico passa a ser uma ferramenta para construir soluções.

MINHA VISÃO / 02

Resolução de problemas

O desenvolvimento passa a ser observado como um processo de análise, planejamento, construção e melhoria de uma solução.

04

Componentes

Alguns dos conhecimentos que formam a base dessa área.

BASE

Lógica de programação

Estruturação do raciocínio para criação de soluções computacionais.

DESENVOLVIMENTO

Construção de sistemas

Organização de estruturas e funcionalidades para aplicações.

WEB

Tecnologias digitais

Utilização de tecnologias voltadas à construção de soluções digitais.

PROJETO

Análise e solução

Compreensão de problemas e transformação deles em soluções estruturadas.

05

Linguagens & ferramentas

Duas tecnologias que representam parte importante da área de desenvolvimento.

Python

Linguagem utilizada para desenvolvimento de aplicações, automação e diferentes soluções computacionais.

Java

Linguagem utilizada na construção de aplicações e sistemas de diferentes escalas.

DIFERENCIAL / SENAC

Conhecimento técnico conectado à prática.

Na minha visão, o diferencial está em trabalhar o desenvolvimento como uma competência aplicada: compreender o problema, organizar a solução, utilizar a tecnologia adequada e transformar conhecimento em algo funcional.
